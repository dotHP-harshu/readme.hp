\n🚀 **EcoTrack**  \n🌱 Track Your Carbon Footprint, Grow a Greener Future\n\n[Report Bug](https://github.com/dothp-harshu/ecotrack/issues/new) | [Request Feature](https://github.com/dothp-harshu/ecotrack/issues/new)\n\n***\n\n📝 **Description**\n\nEcoTrack is a web application designed to help users understand and reduce their environmental impact. By tracking daily activities across six key categories – transportation, electricity, diet, shopping, digital usage, and water consumption – EcoTrack provides personalized insights and actionable recommendations for a more sustainable lifestyle.  It empowers individuals to make informed choices and contribute to a healthier planet.\n\n✨ **Key Features**\n\n- **Carbon Footprint Calculation:** Accurately estimates your monthly carbon emissions.\n- **Detailed Category Breakdown:**  Provides insights into emissions by category (transport, electricity, diet, etc.).\n- **Personalized Recommendations:** Offers tailored tips to reduce your environmental impact.\n- **Interactive Charts:** Visualizes your carbon footprint data for easy understanding.\n- **User Authentication:** Securely manages user data and progress.\n- **AI-Powered Tips:** Generates personalized advice based on your specific data.\n\n🛠️ **Tech Stack**\n\n- **Frontend:** React, Vite, Tailwind CSS, Lucide React\n- **Backend:** Node.js, Express.js\n- **Database:** MongoDB\n- **AI:** OpenAI\n- **Tools:**  npm, Git, GitHub\n\n🚀 **Getting Started**\n\n### Prerequisites\n\n- Node.js v18+\n- npm\n\n### Installation\n\n1. Clone the repository:\n\n   ```bash\n   git clone https://github.com/dothp-harshu/ecotrack.git\n   cd ecotrack\n   ```\n\n2. Install dependencies:\n\n   ```bash\n   cd frontend && npm install\n   cd ../server && npm install\n   ```\n\n3. Configure environment variables:\n\n   - Create a `.env` file in the `server/` directory.\n   - Set values such as:\n\n     ```\n     MONGOOSE_STRING=mongodb://localhost:27017/ecotrack\n     JWT_SECRET=your_jwt_secret\n     OPENROUTER_API_KEY=your_openrouter_api_key\n     ```\n\n4. Run the application in development mode:\n\n   ```bash\n   cd server && npm start\n   cd frontend && npm run dev\n   ```\n\n📂 **Project Structure**\n\n```text\necotrack/\n├── frontend/                # Frontend application\n│   ├── src/\n│   │   ├── components/     # React components\n│   │   ├── pages/          # Application pages\n│   │   ├── assets/         # Images, data, and other assets\n│   │   ├── App.jsx         # Main application component\n│   │   └── index.css       # Global styles\n│   ├── package.json\n│   └── ...\n├── server/                  # Backend API\n│   ├── controllers/        # API logic\n│   ├── models/             # Database models\n│   ├── routes/             # API routes\n│   ├── index.js            # Server entry point\n│   ├── package.json\n│   └── ...\n└── README.md\n```\n\n🤝 **Contributing**\n\nContributions are welcome! 🚀\n\n- Fork the repository.\n- Create a feature branch.\n- Commit your changes with clear messages.\n- Open a Pull Request with a description of your changes.\n\nYou may also:\n\n- Open issues for bugs or feature requests.\n- Improve documentation, tests, or examples.\n\n📜 **License**\n\nDistributed under the [Insert License Here] License.
